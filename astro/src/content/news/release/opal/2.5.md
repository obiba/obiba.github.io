title: "Opal 2.5 Released"
date: "2016-05-16"
product: "opal"
summary: "Improved performance and taxonomy management."
---

<p>We are pleased to announce that Opal 2.5 is now available. <a href="http://www.obiba.org/pages/products/opal/">Opal</a> is OBiBa’s core database application
    for biobanks.</p>

<p>The main new features are:</p>
<ul>
    <li>improved variable taxonomies management, including integrated access to the official <a href="https://github.com/maelstrom-research/maelstrom-taxonomies" target="_blank">Maelstrom Research variable taxonomies</a>,
    </li>
    <li>(very) large derivation scripts are now supported,
    </li>
    <li>improved performance of tabular SQL databases (millions of entities can be handled).
    </li>
</ul>

<p>See <a href="http://wiki.obiba.org/display/OPALDOC">Opal documentation</a> for installation and operation instructions.</p>
