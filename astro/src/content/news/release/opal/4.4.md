date: "2022-05-03"

summary: "Two-factor authentication, Resource views, Personal Access Token expiration, Tasks execution per project, Project backup/restore"
---

<p>We are pleased to announce that Opal 4.4 is now available. <a href="https://www.obiba.org/pages/products/opal/">Opal</a> is OBiBa’s core data management application
    for biobanks.</p>

<p>
  This release introduces the following new features:
</p>

<ul>
  <li><b>Two-factor authentication (2FA)</b>: when the user activates 2FA for its account, an additional temporary key will be requested along with its username/password credentials (see <a href="https://opaldoc.obiba.org/en/latest/web-user-guide/my-profile.html#two-factor-authentication">documentation</a>).
  </li>
  <li><b>Resource views</b>: when a <a href="https://opaldoc.obiba.org/en/latest/resources.html">resource</a> can coerce to a tabular representation, it is now possible to create a view over this resource in order to make the data and their dictionary more accessible for documentation (using Mica) or data extraction (see <a href="https://opaldoc.obiba.org/en/latest/web-user-guide/projects/resources.html">documentation</a>).
  </li>
  <li><b>Personal Access Token (PAT) expiration</b>: for extra security, an end of life can be defined for the PATs (default is to never expire) and an inactivity timeout is now applied (default is 2 months, with the possibility to renew it, see <a href="https://opaldoc.obiba.org/en/latest/web-user-guide/my-profile.html#personal-access-tokens">PAT documentation</a> and <a href="https://opaldoc.obiba.org/en/latest/admin/configuration.html#login-policy-configuration">Login policy configuration</a>).
  </li>
  <li><b>Tasks execution per project</b>: tasks (import, export etc.) will be executed in parallel when they belong to different projects; tasks within a single project are still executed sequentially.
  </li>
  <li><b>Project Backup/Restore</b>: the backup/restore functionality (tables, views, resource references, files, report templates) was only available through the Python and R interfaces. It is now possible to trigger these tasks from each project's administration page.
  </li>
</ul>

<p>
  Opal Python command tool and <a href="https://www.obiba.org/opalr/">Opal R package</a> have been updated according to these new features.
</p>

<p>
  This release is expected to be fully backward compatible.
</p>
