<p>We are pleased to announce that Opal 2.9 is now available. <a href="http://www.obiba.org/pages/products/opal/">Opal</a> is OBiBa’s core database application
    for biobanks.</p>

<p>This release offers the possibility to integrate genotypes data (as files in <a href="https://en.wikipedia.org/wiki/Variant_Call_Format" target="_blank">Variant Call Format </a>) into Opal and make genotypes extractions combined with phenotypes data.</p>

<ul>
    <li>import/export of genotypes data in VCF (or BCF for the binary flavour) format, by using <a href="http://www.htslib.org/" target="_blank">bctools, tabix and bgzip </a> utilities,
    </li>
    <li>basic statistics on VCF/BCF files,
    </li>
    <li>possibility to add samples description (sample, case control) and association with participant,
    </li>
    <li>extraction of participant genotypes matching some phenotypic criteria (ex. get all samples of alcoholic women older than 50 in VCF files).
    </li>
</ul>

<p>Note that this feature is available as a plugin, <a href="https://github.com/obiba/jennite/tree/master/jennite-vcf-store" target="_blank">Jennite VCF Store </a> which must be installed separatly: see <a href="https://wiki.obiba.org/display/OPALDOC/Opal+Plugins+Installation+Guide" target="_blank">Opal Plugins Installation instructions </a>.</p>
