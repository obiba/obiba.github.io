<p>We are pleased to announce that Agate 2.5 is now available. <a href="/pages/products/agate/">Agate</a> is OBiBa’s central user profile server.</p>

<p>
  In this release:
</p>

<ul>
  <li><b>Strong password policy</b>: strong password is now required for new users (min/max length, upper/lower case, digit, special character).
  </li>
  <li><b>Redirect</b>: requests with redirect parameter are verified.
  </li>
  <li><b>Cookies</b>: have <code>Secure</code>, <code>HttpOnly</code> and <code>SameSite</code> flags.
  </li>
  <li><b>CSRF</b>: <a href="https://owasp.org/www-community/attacks/csrf" target="_blank">Cross Site Request Forgery</a> attempts are detected and blocked.
  </li>
  <li><b>Content sanitization</b>: user provided content sanitization to protect from code injection.
  </li>
</ul>
