<p>We are pleased to announce that Agate 1.3 is now available. <a href="/pages/products/agate/">Agate</a> is OBiBa’s central authentication server.</p>

<p>This is mainly a maintenance release: dependencies have been upgraded (more specifically the embedded jetty web server), bugs have been fixed and general robustness has been improved.</p>

<p>New commands have been added to the <a href="https://wiki.obiba.org/display/AGATEDOC/Agate+Python+Client+User+Guide" target="_blank">Agate Python client </a>:</p>
<ul>
		<li>Add/delete user,</li>
		<li>Add/delete group,</li>
		<li>Add/delete application.</li>
	</ul>


<p>
  Agate server upgrade from 1.2 will not affect the data. However some configuration files have been modified. See <a href="https://wiki.obiba.org/display/AGATEDOC/Agate+Configuration+Files#AgateConfigurationFiles-UpgradingtoAgate1.3.x" target="_blank">upgrade to 1.3.x instructions </a>.
</p>

<p>See also <a href="http://wiki.obiba.org/display/AGATEDOC" target="_blank">Agate documentation </a> for installation and operation instructions.</p>
