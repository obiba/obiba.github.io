<p>We are pleased to announce that Agate 3.2 is now available. <a href="/pages/products/agate/">Agate</a> is OBiBa’s central user profile server.</p>

<p>
  Since Agate 3.0, this release requires <b>Java 21</b>. If you are still using Java 8, you must upgrade to Agate 3.0 first.
</p>

<p>
  New features and changes:
</p>

<ul>
    <li>When a user registers from an external realm (most likely using OpenID Connect), through an application, the groups that are assigned to this new user can be configured per application.
    </li>
    <li>The application configuration file is now <b>application-prod.yml</b>. Migration from <i>application.yml</i> to <i>application-prod.yml</i> is done automatically.
    </li>
    <li>The user name can now be an email address.
    </li>
  </ul>

<p>See also <a href="http://agatedoc.obiba.org/" target="_blank">Agate documentation </a> for installation and operation instructions.</p>
