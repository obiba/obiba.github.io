<p>We are pleased to announce that Agate 1.0 is now available. Agate is OBiBa’s central authentication server.</p>

<p>Agate is the user registry of Mica (server and Drupal client) and can be also used as an additional user registry of Opal.</p>

<p>User join requests can be submitted by users, directly from the Agate web interface or through the Mica-Drupal web portal. Agate also offers services of email notifications for the applications.</p>

<p>You can see Agate in action as the <a href="https://portal.partnershipfortomorrow.ca" target="_blank">The Canadian Partnership for Tomorrow Project </a> data portal and the <a href="https://www.maelstrom-research.org/" target="_blank">Maelstrom Research </a> web site.</p>

<p>See also <a href="http://wiki.obiba.org/display/AGATEDOC" target="_blank">Agate documentation </a> for installation and operation instructions.</p>
