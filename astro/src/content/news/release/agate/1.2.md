---
title: "Agate 1.2 Released"
date: "2016-09-07"
product: "agate"
summary: "Multi-language support added"
---

<p>We are pleased to announce that Agate 1.2 is now available. <a href="/pages/products/agate/">Agate</a> is OBiBa’s central authentication server.</p>

<p>This release offers the possibility to:</p>
<ul>
    <li>select the language of the interface,
    </li>
    <li>edit and extend the translations of the interface, including the signup form,
    </li>
    <li>define the preferred language of a user.
    </li>
</ul>

<p>
  Agate server upgrade from 1.1 will not affect the data.
</p>

<p>See also <a href="http://wiki.obiba.org/display/AGATEDOC" target="_blank">Agate documentation </a> for installation and operation instructions.</p>
