<p xmlns="http://www.w3.org/1999/html">We are pleased to announce that Mica2 5.4 is now available. <a
    href="/pages/products/mica/">Mica</a> is OBiBa’s data web portal for epidemiological studies and harmonization
  initiatives.</p>

<p>
  This release includes the following features:
</p>

<ul>
  <li><b>2FA enforcement</b>, requires <b>Agate 2.10</b> or later.
  </li>
  <li><b>Data Access forms download in Word format</b>, is available to administrators and data access officers, to facilitate data access request review with field entries commenting.
  </li>
  <li><b>Data Access identifiers</b> can be incremental, instead of being generated randomly.
  </li>
</ul>

<p>
  This release was possible thanks to the funding of the <a href="https://www.lumc.nl/" target="_blank">Leiden University Medical Center - LUMC </a>, and of the <a href="https://www.mirec-canada.ca/" target="_blank">MIREC Biobank </a>.
</p>

<p>See <a href="http://micadoc.obiba.org" target="_blank">Mica documentation <i
      class="fa fa-external-link-square"></i></a> for installation and operation instructions.</p>
