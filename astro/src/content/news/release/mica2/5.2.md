---

<p xmlns="http://www.w3.org/1999/html">We are pleased to announce that Mica2 5.2 is now available. <a
    href="/pages/products/mica/">Mica</a> is OBiBa’s data web portal for epidemiological studies and harmonization
  initiatives.</p>

<p>This release includes the following new features:</p>

<ul>
  <li><b>Removal of Opal dependency </b> as the main data provider:
    <ul class="">
      <li>
        <b>Collected Datasets and Harmonization Protocols </b> can now import their data from files or a generic data
        schema definition.
      </li>
      <li>
        <b>Taxonomies</b> can now be imported from YAML files.
      </li>
    </ul>
  </li>
  <li><b>Individual Studies</b> that do not have any associated variables can be annotated by taxonomy vocabularies.
  </li>
</ul>

<p>The following main templates have been modified:</p>
<ul>
  <li><b>libs/annotations.ftl</b>: contains a collection of macros required to list annotations.
  </li>
  <li><b>study.ftl</b>: addition of annotations section for individual studies only.
  </li>
  <li><b>network.ftl</b>: addition of annotations section.
  </li>
</ul>

<div class="alert alert-info obiba-top-margin" role="alert">
  <p>A quick note on <code>entityAnnotations</code> macro:</p>
  <p>Parameters to pass:</p>
  <ul>
    <li><i></i>
      <b>annotations</b>: list of annotations provided by the server.
    </li>
    <li><i></i>
      <b>showCount</b>: each annotation is comlpemented by the count of its corresponding individual studies (only
      useful in network pages).
    </li>
  </ul>
  <p>Here is a snippet to be used in the <code>network.ftl</code>:</p>
  <pre>&lt;#if annotations?size gt 0&gt;&lt;@entityAnnotations annotations=annotations showCount=true/&gt;&lt;/#if&gt;</pre>
</div>
