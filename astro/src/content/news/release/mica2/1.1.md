<p>We are pleased to announce that Mica2 1.1 is now available. <a href="/pages/products/mica/">Mica</a> is OBiBa’s data web portal for biobanks.</p>

<p>The main new features are:</p>
<ul>
    <li>Email notifications can be sent at any stage of the publication flow (requires latest <a href="/pages/products/agate/">Agate</a>),
    </li>
    <li>Comments can be done on the draft version of any document (network, study, dataset) to facilitate the edition/publication team collaboration,
    </li>
    <li>Access control to published content (visible from the Mica portal) can be granted on a user or group basis,
    </li>
    <li>A network can be a member of another network,
    </li>
    <li>Study and Network member roles can be customized (defaults are <em>contact</em> and <em>investigator</em>).
    </li>
</ul>

<p>Mica2 server upgrade from 1.0 will not affect the data.</p>

<p>See also <a href="http://wiki.obiba.org/display/MICADOC" target="_blank">Mica documentation </a> for installation and operation instructions.</p>
