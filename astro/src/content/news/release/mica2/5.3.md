<p xmlns="http://www.w3.org/1999/html">We are pleased to announce that Mica2 5.3 is now available. <a
    href="/pages/products/mica/">Mica</a> is OBiBa’s data web portal for epidemiological studies and harmonization
  initiatives.</p>

<p>
  This release includes the new feature related to harmonization protocols, namely, the retrieval of harmonization status statistics per study-specific datasets. Currently, only a handful of cohorts use this feature, here are some examples:
</p>

<ul>
  <li><a href="https://www.maelstrom-research.org/dataset/canpath-bl-hrfq-hp/"  target="_blank">Maelstrom Research </a>
  </li>
  <li><a href="https://portal.canpath.ca/dataset/cptp_bl_hrfq"  target="_blank">The Canadian Partnership for Tomorrow's Health (CanPath) </a>
  </li>
  <li><a href="https://portal-dev.citf.mcgill.ca/dataset/citf-bl-demographics-hp"  target="_blank">COVID-19 Immunity Task Force (CITF) </a>
  </li>
</ul>  

<p>See the percentages under each study-specific dataset in the harmonization potential table. A mouse over will provide the detailed counts of each harmonization status.</p>

<div class="alert alert-info obiba-top-margin" role="alert">
<p>This is primarily a back-end feature in response to specific requests from cohorts that have a lot of harmonization information. Currently, this feature is not implemented in the default Mica public pages but may be included in future releases depending on cohort feedback.</p>
</div>

  This release was possible thanks to the development contributions of <a href="https://www.maelstrom-research.org" target="_blank">Maelstrom Research</a> </a>.
