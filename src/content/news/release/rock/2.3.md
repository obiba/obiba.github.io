---

<p>We are pleased to announce that Rock 2.3 is now available. <a href="/pages/products/rock/">Rock</a> is OBiBa’s R computation engine.</p>

<p>
  This Rock release includes:
</p>

<ul>
    <li>GraalVM native binaries (Linux amd64 and arm64) are built on release, as an alternative to running Rock on the JVM. The goal is to provide Docker images based on the <a href="https://rocker-project.org/" target="_blank">Rocker project</a> with super fast startup.
    </li>
    <li>Security fix: Bouncy Castle upgraded to 1.86.
    </li>
    <li>R repositories configuration clarified: the REST API uses <code>r.repos</code> from <code>application.yml</code>, while the <code>repos</code> option of <code>Rprofile.R</code> only applies to R sessions. The unmaintained <code>cran.obiba.org</code> repository was removed from the defaults.
    </li>
  </ul>

<p>
  Additional notes:
</p>

<ul>
    <li>No upgrade action required when Rock is deployed with Docker, just pull the latest image.
    </li>
    <li>The Rock API has NOT been modified: it will seamlessly integrate with <b>Opal</b>.
    </li>
  </ul>

<p>See also <a href="http://rockdoc.obiba.org/" target="_blank">Rock documentation </a> for installation and operation instructions.</p>
