<p>We are pleased to announce that Agate 3.3 is now available. <a href="/pages/products/agate/">Agate</a> is OBiBa’s
  central user profile server.</p>

<p>
  Since Agate 3.0, this release requires <b>Java 21</b>. If you are still using Java 8, you must upgrade to Agate 3.0
  first.
</p>

<p>
  New features and changes:
</p>

<ul>
  <li>New administration UI.
  </li>
  <li>Security related improvements and dependencies upgrade.
  </li>
</ul>

<p>See also <a href="http://agatedoc.obiba.org/" target="_blank">Agate documentation <i
      class="fa fa-external-link-square"></i></a> for installation and operation instructions.</p>
