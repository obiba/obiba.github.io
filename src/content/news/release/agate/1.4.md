date: "2018-09-25"

summary: "Data access request amendments notifications"
---

<p>We are pleased to announce that Agate 1.4 is now available. <a href="/pages/products/agate/">Agate</a> is OBiBa’s central authentication server.</p>

<p>This is mainly a maintenance release: dependencies have been upgraded (more specifically the javascript UI framework).</p>

<p>New notification email templates have also been added to address <a href="/pages/products/mica/">Mica</a>'s new feature (version 3.4.0, to be released): data access requests can be amended.</p>

<p>See also <a href="http://agatedoc.obiba.org/" target="_blank">Agate documentation </a> for installation and operation instructions.</p>
