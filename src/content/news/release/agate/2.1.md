<p>We are pleased to announce that Agate 2.1 is now available. <a href="/pages/products/agate/">Agate</a> is OBiBa’s central user profile server.</p>

<p>
  Agate server can be run in a context path: the server URL can now be <code>https://example.org/agate</code> and not just in a subdomain such as <code>https://agate.example.org</code>.
</p>

<p>New email template added for the "Contact Us" page of Mica 4.3.x. This is to be used when a user (not necessarily authenticated) wants to reach Mica's administrators or data access officers.</p>

<p>
  This release was possible thanks to the funding of <a href="https://canpath.ca/" target="_blank">CanPath </a> (data cataloging and data access requests) and the <a href="https://www.eucanconnect.eu/" target="_blank">EUCAN Connect </a> (<a href="https://www.eucanconnect.eu/coral-docker-stack-deployment/" target="_blank">Coral</a> integration) programs.
</p>

<p>See also <a href="http://agatedoc.obiba.org/" target="_blank">Agate documentation </a> for installation and operation instructions.</p>
