<p>We are pleased to announce that Agate 2.4 is now available. <a href="/pages/products/agate/">Agate</a> is OBiBa’s central user profile server.</p>

<p>
  In this release:
</p>

<ul>
  <li><a href="https://agatedoc.obiba.org/en/latest/web-user-guide/realms.html#open-id-connect-realm" target="_blank">OpenID Connect realms </a> username and groups extraction process can be configured,</li>
  <li>Username can be an email,</li>
  <li>Improved client IP detection.</li>
</ul>

<p>
  This release was possible thanks to the funding of the <a href="https://www.eucanconnect.eu/" target="_blank">EUCAN Connect </a> (<a href="https://www.eucanconnect.eu/coral-docker-stack-deployment/" target="_blank">Coral</a> integration) program.
</p>

<p>See also <a href="http://agatedoc.obiba.org/" target="_blank">Agate documentation </a> for installation and operation instructions.</p>
