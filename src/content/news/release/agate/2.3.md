<p>We are pleased to announce that Agate 2.3 is now available. <a href="/pages/products/agate/">Agate</a> is OBiBa’s central user profile server.</p>

<p>
  In this release:
</p>

<ul>
    <li>Best efforts are done to get clients' IP, despite the reverse proxies, so that it appears in the web services resquests log (rest.log),
    </li>
    <li>Dependency on Google fonts service removed, so that pages work in restricted environments.
    </li>
</ul>

<p>
  This release was possible thanks to the funding of the <a href="https://www.eucanconnect.eu/" target="_blank">EUCAN Connect </a> (<a href="https://www.eucanconnect.eu/coral-docker-stack-deployment/" target="_blank">Coral</a> integration) program.
</p>

<p>See also <a href="http://agatedoc.obiba.org/" target="_blank">Agate documentation </a> for installation and operation instructions.</p>
