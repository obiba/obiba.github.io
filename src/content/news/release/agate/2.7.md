title: "Agate 2.7 Released"
date: "2022-09-05"
product: "agate"
summary: "Database driver upgrade, Single sign-out support"
---

<p>We are pleased to announce that Agate 2.7 is now available. <a href="/pages/products/agate/">Agate</a> is OBiBa’s central user profile server.</p>

<p>
  In this release:
</p>

<ul>
  <li><b>MongoDB driver upgrade</b>: latest java driver is used (4.7 at the time of release). No database upgrade is required, as this driver is backward compatible with older versions (see <a href="https://www.mongodb.com/docs/drivers/java/sync/current/compatibility/" target="_blank">MongoDB Java Driver Compatibility Matrix </a>)
  </li>
  <li><b>OAuth2 Logout Endpoint</b>: this can be triggered to perform single sign-out (following <a href="https://openid.net/specs/openid-connect-session-1_0-17.html#RPLogout" target="_blank">OpenID Connect's specification </a>). It is described by the key "end_session_endpoint" in the OpenID Connect discovery object (see <a href="https://agate-demo.obiba.org/.well-known/openid-configuration" target="_blank">agate-demo's one </a>).
  </li>
  <li><b>Sign-out</b>: the sign-out procedure now cascades the logout action to the external Identity Providers. For instance, if a user authenticates in Agate via an external ID provider (using OpenID Connect), this ID provider session's will be automatically ended after the Agate's one is ended.
  </li>
  <li>Many library dependencies upgraded, fixing some potential security issues.
  </li>
</ul>
