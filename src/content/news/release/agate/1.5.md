---
title: "Agate 1.5 Released"
date: "2019-08-14"
product: "agate"
summary: "OpenID Connect, authentication delegation"
---

<p>We are pleased to announce that Agate 1.5 is now available. <a href="/pages/products/agate/">Agate</a> is OBiBa’s central authentication server.</p>

<p>Thanks to the support of the <a href="https://www.canarie.ca/" target="_blank">Canarie </a> program, this release introduces the ability for Agate to delegate authentication to third party services such as LDAP/Active Directory or a SQL database or <a href="https://openid.net/connect/" target="_blank">OpenID Connect </a> providers (for instance <a href="https://www.keycloak.org/" target="_blank">Keycloak </a> is a well established open source solution). Agate can also act itself as an OpenID Connect provider.</p>

<p>See also <a href="http://agatedoc.obiba.org/" target="_blank">Agate documentation </a> for installation and operation instructions.</p>
