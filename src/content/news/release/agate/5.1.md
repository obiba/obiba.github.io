<p>We are pleased to announce that Agate 5.1 is now available. <a href="/pages/products/agate/">Agate</a> is OBiBa’s central user profile server.</p>

<p>
  This Agate release includes:
</p>

<ul>
    <li><strong>Fallback notification templates</strong>: an application can fall back to another notification templates folder (the bundled Mica one, or any folder under <code>AGATE_HOME/conf/templates/notifications/</code>) for any template missing from its own folder. The fallback is selected in the application dialog of the administration UI; the default is no fallback.
    </li>
    <li><strong>Mica publication notifications</strong>: new templates for the e-mails Mica sends when a study, network, project, dataset or file is published or unpublished. The dataset status change templates were renamed to match Mica's type names (<code>collected-datasetStatusChanged</code>, <code>harmonized-datasetStatusChanged</code>).
    </li>
    <li><strong>Template validation</strong>: the template editor now reports, as a warning and in the preview, malformed directives that would otherwise be sent verbatim in e-mails.
    </li>
    <li><strong>Public URL</strong>: when not set, the public URL is initialized from the <code>agate.public-url</code> property (<code>AGATE_PUBLIC_URL</code> environment variable).
    </li>
    <li><strong>Security improvements</strong>: the password reset key no longer carries the password hash (older reset links are rejected), and clearer error messages on realm creation.
    </li>
    <li><strong>New look</strong>: the user interface was rebranded with the OBiBa design system.
    </li>
  </ul>

<p>
  If you have overridden the Mica notification templates or their messages, please read the <a href="https://github.com/obiba/agate/blob/master/UPGRADE.md" target="_blank">Agate upgrade notes </a> for the renamed templates and message keys.
</p>
