---
title: "Agate 1.1 Released"
date: "2016-05-04"
product: "agate"
summary: "OAuth2 and OpenID Connect support added."
---

<p>We are pleased to announce that Agate 1.1 is now available. Agate is OBiBa’s central authentication server.</p>

<p>This release offers the possibility (for applications that are not part of the OBiBa software suite) to use Agate as a standard Authentication and ID provider.</p>

<p>The main new features are:</p>
<ul>
    <li>support of main <a href="http://tools.ietf.org/html/rfc6749" target="_blank">OAuth2</a> specifications,
    </li>
    <li>support of main <a href="http://openid.net/specs/openid-connect-core-1_0.html" target="_blank">Open ID Connect</a> specifications,
    </li>
    <li>Single Sign-On is available within OBiBa software suite.
    </li>
</ul>

<p>See also <a href="http://wiki.obiba.org/display/AGATEDOC" target="_blank">Agate documentation </a> for installation and operation instructions.</p>
