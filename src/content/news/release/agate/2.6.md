<p>We are pleased to announce that Agate 2.6 is now available. <a href="/pages/products/agate/">Agate</a> is OBiBa’s central user profile server.</p>

<p>
  In this release:
</p>

<ul>
  <li><b>Two-factor authentication</b>: 2FA can be enabled for users managed by Agate.
  </li>
  <li><b>Multi-domain OIDC setup</b>: when the same Agate server is accessed from different URLs, the OpenID Connect mechanism behaves consistently.
  </li>
</ul>

  This release was possible thanks to the funding of the <a href="https://www.eucanconnect.eu/" target="_blank">EUCAN Connect </a> (<a href="https://www.eucanconnect.eu/coral-docker-stack-deployment/" target="_blank">Coral</a> integration) program, and to the contribution of <a href="https://www.lumc.nl/" target="_blank">LUMC </a>.
</p>
