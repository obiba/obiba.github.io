date: "2015-12-04"
product: "onyx"
summary: "Upgrade to Java8 and advanced cache support."
---

<p>We are pleased to announce that Onyx 1.10 is now available. Onyx is OBiBa’s data collection application for biobanks.</p>

<p>The main new features are:</p>
<ul>
    <li>Upgrade of java runtime to java8,
    </li>
    <li>External datasources cache support, improving performance and onyx system resilience to remote datasource failure.
    </li>
</ul>
