<p>We are pleased to announce that Amber 3.0 is now available. <a href="/pages/products/amber/">Amber</a> is OBiBa’s electronic data capture solution.</p>

<p>
  This Amber release includes:
</p>

<ul>
    <li><strong>JSON Forms support</strong>: form schemas can be imported and exported in the <a href="https://www.obiba.org/quasar-json-form/" target="_blank">JSON Forms</a> format.
    </li>
    <li><strong>File items</strong>: case report forms and interviews can now capture files. Amber Collect and Amber Visit queue files while offline and upload them on save, and Amber Studio allows to preview file controls and download record files.
    </li>
    <li><strong>Amber Visit as a progressive web app</strong>: interviews can be run offline, with automatic saving of pending steps.
    </li>
    <li><strong>Data extraction and audit</strong>: API keys for data extraction, an audit view, and export fixes for Opal import.
    </li>
  </ul>

<p>
  See the <a href="https://github.com/obiba/amber/releases/tag/3.0.0" target="_blank">full release notes </a> for the complete list of changes.
</p>
