date: "2016-11-01"

summary: "Improved performance, tabular SQL as identifiers database, MariaDB, R/DataSHIELD workspaces and much more."
---

<p>We are pleased to announce that Opal 2.6 is now available. <a href="http://www.obiba.org/pages/products/opal/">Opal</a> is OBiBa’s core database application
    for biobanks.</p>

<div class="alert alert-warning" role="alert">
	<strong>Java 8 is now a requirement</strong>.
	As Java 7 support by Oracle has ended a while ago and because Java 8 is much better at handling collections (parallelization of computations for instance), all OBiBa software now require Java 8. See Java instructions specific to your system for upgrading.
</div>

<p>The main new features are:</p>
<ul>
    <li>improved performance: parallelization of read and write operations as much as possible,
    </li>
    <li>identifiers database can use the tabular SQL schema,
    </li>
    <li>support of <a href="https://mariadb.org" target="_blank">MariaDB </a> databases,
    </li>
    <li>R/DataSHIELD workspaces: R server session can be saved and restored,
    </li>
    <li>R files API: Opal files can be pushed to/pulled from the R server session,
    </li>
    <li>R data API: any R object can be sent from the R client session to the R server session.
    </li>
</ul>

<p>To benefit from the new R/DataSHIELD functionalities, the R opal package is to be upgraded as well (at least version 2.3.0). See <a href="https://wiki.obiba.org/display/OPALDOC/Opal+R+User+Guide#OpalRUserGuide-Installation" target="_blank">Opal R package installation </a> instructions.</p> 

<p>See <a href="http://wiki.obiba.org/display/OPALDOC" target="_blank">Opal documentation </a> for installation and operation instructions.</p>
