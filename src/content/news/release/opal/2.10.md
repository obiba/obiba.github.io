<p>We are pleased to announce that Opal 2.10 is now available. <a href="http://www.obiba.org/pages/products/opal/">Opal</a> is OBiBa’s core database application
    for biobanks.</p>

<p>This release introduces new pages and web services to perform advanced search both on variables and entities:</p>

<ul>
    <li>variables can be searched using controlled vocabularies (as specified by the taxonomies) and/or full-text search; found variables can be added to a cart for further processing,
    </li>
    <li>a specific entity can be searched by its type and identifier,
    </li>
    <li>entities matching variable criteria (from different tables) can be counted and listed; a view can be created to match these filtered entities.
    </li>
</ul>

<p>A variable cart can be filled-in by the user for further processing:</p>

<ul>
    <li>variables can be added to the cart by individual or group selection when browsing table dictionaries, or by selecting the variables resulting of a search operation,
    </li>
    <li>variables from the cart can be used to make a view, build variable criteria of an entities search operation, or apply/remove controlled vocabulary (taxonomy) annotations in batch.
    </li>
</ul>

<p>Other notable features are:</p>

<ul>
    <li>the variable attributes handling and rendering has been improved by using the controlled vocabularies,
    </li>
    <li>the search engine implementation (based on <a href="https://www.elastic.co/products/elasticsearch" target="_blank">Elasticsearch </a>) has been wrapped in a plugin,
    </li>
    <li>the plugins can be managed from the Administration page based on a plugin repository (configurable, default is <a href="https://plugins.obiba.org/stable/" target="_blank">OBiBa plugins repository </a>).
    </li>
    <li>addition of new python commands to backup and restore annotations (<a href="https://wiki.obiba.org/display/OPALDOC/Export+Annotations+Command" target="_blank">export-annot </a> and <a href="https://wiki.obiba.org/display/OPALDOC/Import+Annotations+Command" target="_blank">import-annot </a>),
    </li>
    <li>addition of new javascript methods to handle longitudinal and repeated measures data (<a href="https://wiki.obiba.org/display/OPALDOC/filter+method" target="_blank">filter </a>, <a href="https://wiki.obiba.org/display/OPALDOC/subset+method" target="_blank">subset </a>, <a href="https://wiki.obiba.org/display/OPALDOC/trimmer+method" target="_blank">trimmer </a>, <a href="https://wiki.obiba.org/display/OPALDOC/reduce+method" target="_blank">reduce </a> and <a href="https://wiki.obiba.org/display/OPALDOC/insertAt+method" target="_blank">insertAt </a>),
    </li>
    <li>improvement of some javascript methods to handle longitudinal and repeated measures data (<a href="https://wiki.obiba.org/display/OPALDOC/any+method" target="_blank">any </a> and <a href="https://wiki.obiba.org/display/OPALDOC/map+method" target="_blank">map </a>).
    </li>
</ul>

<div class="alert alert-warning obiba-top-margin" role="alert">
    <strong>Opal Search Plugin note</strong>.
    As search engine implementation is now available from a plugin, Opal will automatically download (when installing or upgrading from previous versions) the Opal Search ES 1.0.x plugin (based on <a href="https://www.elastic.co/products/elasticsearch" target="_blank">Elasticsearch </a> 2.4.5) from the <a href="https://plugins.obiba.org/stable/" target="_blank">OBiBa plugins repository </a>. If the plugins repository cannot be reached (due to network restrictions for instance), the search capability of Opal will not be available. The plugin can be installed afterwards; see <a href="http://wiki.obiba.org/display/OPALDOC/Opal+Plugins+Installation+Guide" target="_blank">Opal Plugins Installation documentation </a>.
</div>
