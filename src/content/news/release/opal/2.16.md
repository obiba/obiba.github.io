---

<p>We are pleased to announce that Opal 2.16 is now available. <a href="http://www.obiba.org/pages/products/opal/">Opal</a> is OBiBa’s core database application
    for biobanks.</p>

<p>This release facilitates the documentation of the harmonization process by reading directly the variable properties from the column attributes of the R data.frame/tibble objects. Thus harmonization algorithms can be implemented along with their documentation in the metadata of the datasets. This approach has been successfully applied by the <a href="https://www.maelstrom-research.org/" target="_blank">Maelstrom Research </a> group. As a complement, the
<a href="https://cran.r-project.org/package=opalr" target="_blank">opalr </a> R package provides some new utility functions (since version 1.3.0) for retrieving datasets from Opal into the local R session, annotating the harmonized datasets with taxonomy terms, applying data dictionary, and saving back the datasets as Opal tables.
</p>

<p>
  Additional features implemented:
</p>

<ul>
    <li><a href="http://opaldoc.obiba.org/en/latest/magma-user-guide/sequence/index.html" target="_blank">value sequence functions </a> <code>median</code> and <code>unique</code> have been added,
    </li>
    <li>the data summary of temporal (date/datetime), geospatial (point/linestring/polygon) and text variables has been improved to support case of continuous data with only categories describing missing values,
    </li>
    <li>the data dictionary of an imported dataset can be optionaly merged into the existing destination table (default behavior is still override).
    </li>
</ul>
