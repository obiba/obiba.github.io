<p>We are pleased to announce that Opal 2.8 is now available. <a href="http://www.obiba.org/pages/products/opal/">Opal</a> is OBiBa’s core database application
    for biobanks.</p>


<h4>R integration</h4>

<p>This release is the continuation of version 2.7: the support of time series and longitudinal data in R has been improved (one line per event occurrence in the assigned data frame).</p>

<p>Opal will also rely on <a href="http://tidyverse.org" target="_blank">tidyverse </a>, a collection of R packages that follow the <a href="http://r4ds.had.co.nz/" target="_blank">R for Data Science </a> recommendations, to provide the following functionalities:</p>

<ul>
    <li>import/export of data in SAS, SPSS or Stata format, by using the R package <a href="http://tidyverse.org" target="_blank">haven </a>,
    </li>
    <li>import of R data frames (more specifically <a href="https://github.com/tidyverse/tibble" target="_blank">tibble </a> data frames) as tables in Opal, allowing to perform data cleansing, derivation and harmonization in R.
    </li>
</ul>

<p>This Opal server release is to be used in combination with the latest <a href="https://wiki.obiba.org/display/OPALDOC/R+Server+Installation+Guide" target="_blank">Opal R server </a> package, that will install on the server side the required R and system packages:</p>

<ul>
    <li><a href="http://tidyverse.org" target="_blank">tidyverse </a> for the previously mentioned functionalities,
    </li>
    <li><a href="http://rmarkdown.rstudio.com/" target="_blank">rmarkdown </a> along with <a href="http://pandoc.org/" target="_blank">pandoc </a> for generating reports in PDF format.
    </li>
</ul>

<p>On the client side, the latest release of the <a href="https://wiki.obiba.org/display/OPALDOC/Opal+R+User+Guide" target="_blank">opal R package </a> will give access to the <a href="http://tidyverse.org" target="_blank">tidyverse </a> related functionalities and will also allow full management of files in Opal (upload, download, create directory, move, copy etc.).</p>

<h4>View join tables</h4>

<p>This release of Opal improves the join of tables in a view:</p>

<ul>
    <li>the entities of a "inner" join table will not be added to the set of entities of the view, introducing a new way to specify the entities of a view,
    </li>
    <li>the join tables can be ordered, affecting the order of the value sequences when a variable is defined in several of these tables.
    </li>
</ul>
