<p>We are pleased to announce that Opal 6.2 is now available. <a
    href="https://www.obiba.org/pages/products/opal/">Opal</a> is OBiBa’s core data management application
  for biobanks.</p>

<p>
  This Opal release includes:
</p>

<ul>
    <li><strong>Versions of a view</strong>: the history of changes of a view, its entity filter and its derived variables can be browsed, compared and restored. A script can be viewed at any version.
    </li>
    <li><strong>Tags of a view</strong>: a version of a view can be tagged, for instance to mark the one used for a publication. A tag can be downloaded, restored, or used to create a new view.
    </li>
    <li><strong>Views using a table</strong>: the table page lists the views that refer to it, and a table or a view cannot be removed or renamed while a view uses it.
    </li>
    <li><strong>Permissions</strong>: changing how a view computes its values requires access to the values of its sources, and only a system administrator can delete tasks.
    </li>
    <li><strong>SAS Transport</strong>: the deprecated SAS export is replaced by the SAS Transport (XPT) format.
    </li>
    <li><strong>Performance</strong>: the entities of the views are cached on disk and kept across restarts.
    </li>
  </ul>

<p>
  See the <a href="https://github.com/obiba/opal/releases/tag/6.2.0" target="_blank">full release notes </a> for the complete list of changes.
</p>

<p>See also <a href="https://opaldoc.obiba.org/" target="_blank">Opal documentation </a> for installation and operation instructions.</p>
