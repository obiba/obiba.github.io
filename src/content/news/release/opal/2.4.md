---
title: "Opal 2.4 Released"
date: "2015-09-24"
product: "opal"
summary: "This release includes PostgreSQL support and a new SQL data schema enabling import/export of plain SQL tables."
---

<p>We are pleased to announce that Opal 2.4 is now available. Opal is OBiBa’s core database application
    for biobanks.</p>

<p>The main new features are:</p>
<ul>
    <li>support of a new SQL data schema that allows to import/export data from/to plain SQL tables,
    </li>
    <li>PostgreSQL support,
    </li>
    <li>improved data import performance,
    </li>
    <li>RPM packaging for CentOS-like systems.
    </li>
</ul>
<p>See full release note <a href="http://wiki.obiba.org/display/CAG/2015/09/24/Opal+2.4+Released">here</a></p>
