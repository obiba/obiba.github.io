date: "2015-02-26"

summary: "Improved R integration and taxonomies addition."
---

<p>We are pleased to announce that Opal 2.3 is now available. Opal is OBiBa’s core database application
    for biobanks.</p>

<p>The main new features are:</p>
<ul>
    <li>R integration improvements (session monitoring, large datasets handling),
    </li>
    <li>addition of taxonomies, which are a simple way to describe variable attributes,
    </li>
    <li>support for markdown format in variable attributes (edition and preview),
    </li>
    <li>variable ordering.
    </li>
</ul>
<p>See full release note <a href="http://wiki.obiba.org/display/CAG/2015/02/26/Opal+2.3+released">here</a></p>
