<p>We are pleased to announce that Opal 2.0 is now available. Opal is OBiBa’s core database application
    for biobanks.</p>

<p>Opal 2.0 is a major release that introduces many features and bug fixes. This release also offers a
    complete rework of the web user interface.</p>

<p>The main new features are:</p>
<ul>
    <li>the concept of project (previously known as
        datasource) has been added,
    </li>
    <li>edition of dictionaries is made easier,</li>
    <li>improved data exploration,</li>
    <li>improved management of identifiers mappings,
    </li>
    <li>improved user management,</li>
    <li>better integration with R,</li>
    <li>many other server improvements, including the
        support of MongoDB.
    </li>
</ul>
