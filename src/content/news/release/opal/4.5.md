---
title: "Opal 4.5 Released"
date: "2022-09-16"
product: "opal"
summary: "Database drivers upgrade, Single sign-out support, Logout redirection"
---

<p>We are pleased to announce that Opal 4.5 is now available. <a href="https://www.obiba.org/pages/products/opal/">Opal</a> is OBiBa’s core data management application
    for biobanks.</p>

<p>
  In this release:
</p>

<ul>
    <li><b>MongoDB driver upgrade</b>: latest java driver is used (4.7 at the time of release). No database upgrade is required, as this driver is backward compatible with older versions (see <a href="https://www.mongodb.com/docs/drivers/java/sync/current/compatibility/" target="_blank">MongoDB Java Driver Compatibility Matrix </a>)
    </li>
    <li><b>SQL drivers upgrade</b>: latest java drivers are used for MySQL, MariaDB and PostgreSQL databases. No database upgrade is required.
    </li>
    <li><b>Logout with OpenID Connect</b>: the sign-out procedure now cascades the logout action to the external Identity Providers. For instance, if a user authenticates in Opal via an external ID provider (using OpenID Connect), this ID provider session's will be automatically ended after the Opal's one is ended.
    </li>
    <li><b>Logout redirection</b>: it is now possible to specify where the user should be redirected after logout (for instance the institution's home page).
    </li>
    <li>Many library dependencies upgraded, fixing some potential security issues.
    </li>
  </ul>

<p>
  This release is expected to be fully backward compatible.
</p>
