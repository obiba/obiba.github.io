---
title: "Opal 4.1 Released"
date: "2021-04-27"
product: "opal"
summary: "SQL API, Personal Access Token with read-only support"
---

<p>We are pleased to announce that Opal 4.1 is now available. <a href="https://www.obiba.org/pages/products/opal/">Opal</a> is OBiBa’s core data management application
    for biobanks.</p>

<p>
  This release of Opal introduces the following new features:
</p>

<ul>
    <li>SQL API, to perform SQL queries on Opal's tables from the <a href="https://opaldoc.obiba.org/en/latest/web-user-guide/projects/tables.html#sql" target="_blank">Project's web interface </a>, or using the <a href="https://rdocumentation.org/packages/opalr/versions/2.1.0/topics/opal.sql" target="_blank">opalr R package </a> or from the <a href="https://opaldoc.obiba.org/en/latest/python-user-guide/datasources/sql.html" target="_blank">Opal SQL Python command </a>,
    </li>
    <li>new <a href="https://opaldoc.obiba.org/en/latest/web-user-guide/my-profile.html#personal-access-tokens" target="_blank">Personal Access Token read-only scope </a>, with or without access to individual-level data,
    </li>
    <li>data assignment to the DataSHIELD/R server are much faster thanks to a new caching system.
    </li>
</ul>

<p>
  No breaking changes are expected with this release.
</p>

<p>
As a reminder, following the announcement that the Bintray repository will be deprecated, the OBiBa software are now available at <a href="https://obiba.jfrog.io/">obiba.jfrog.io</a>. What you need to do is to follow instructions for the <a href="https://www.obiba.org/pages/pkg/">Debian repository</a> and for the <a href="https://www.obiba.org/pages/rpm/">RPM repository</a>.
</p>
