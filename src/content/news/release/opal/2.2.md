<p>We are pleased to announce that Opal 2.2 is now available. Opal is OBiBa’s core database application
    for biobanks.</p>

<p>The main new features are:</p>
<ul>
    <li>rows can be filtered by specifying the "entity filter" of a view in javascript,
    </li>
    <li>several Python commands have been added (permissions and data management),
    </li>
    <li>new javascript functions have been added,
    </li>
    <li>task progress is reported in the web UI,
    </li>
    <li>a project can be archived,
    </li>
    <li>data indexing can be suspended.
    </li>
</ul>
