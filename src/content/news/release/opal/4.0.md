title: "Opal 4.0 Released"
date: "2021-03-08"
product: "opal"
summary: "Cluster of Rock R servers, RDS import/export"
---

<p>We are pleased to announce that Opal 4.0 is now available. <a href="https://www.obiba.org/pages/products/opal/">Opal</a> is OBiBa’s core data management application
    for biobanks.</p>

<p>
  This release of Opal integrates with the <a href="https://www.obiba.org/pages/products/rock/">Rock R server</a> which is a modern implementation of a R server with a REST API, built-in security and the capability of scaling horizontaly: Opal can connect with multiple R servers, grouped in a cluster. This allows to balance the load of the analysis between multiple computation nodes. This fully integrates with the <a href="https://datashield.ac.uk" target="_blank">DataSHIELD </a> federated analysis platform.
</p>

<p>
  <img alt="R servers" src="https://opaldoc.obiba.org/en/latest/_images/opal-rock-scalability.png" width="800">
</p>

<p>
  Additional features implemented:
</p>

<ul>
    <li>import/export data in RDS format (single serialized R object, see <a href="https://www.rdocumentation.org/packages/base/versions/3.6.2/topics/readRDS" target="_blank">base::readRDS </a> documentation), also available as import/export python commands,
    </li>
    <li>new <a href="https://opaldoc.obiba.org/en/latest/python-user-guide/permission/index.html" target="_blank">Resource permissions python commands </a> for adding/deleting permissions on a project's resources,
    </li>
    <li>the R REST API now returns either binary serialized R objects (as before) or JSON serialized R objects, which makes the Opal's R service usable by non-R clients,
    </li>
    <li>R markdown report additional files (R script to source, subsection of R markdown, images etc.) are supported for building complex reports.
    </li>
</ul>

<p>
  <b>Breaking changes</b>
</p>

<p>
  Despite Opal is backward compatible with the legacy R servers, some breaking changes are expected with this release:
</p>

<ul>
    <li>R based plugins need to be upgraded. This will be done automatically by Opal (requires internet connection),
    </li>
    <li><a href="https://github.com/obiba/opalr" target="_blank">opalr </a> needs to be upgraded to its latest version (otherwise JSON serialized R objects will be returned). Use the following R command:
    </li>
</ul>

<pre>
install.packages("opalr")
</pre>
