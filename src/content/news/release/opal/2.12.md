---
title: "Opal 2.12 Released"
date: "2018-09-26"
product: "opal"
summary: "Datasource plugins, improved R API"
---

<p>We are pleased to announce that Opal 2.12 is now available. <a href="http://www.obiba.org/pages/products/opal/">Opal</a> is OBiBa’s core database application
    for biobanks.</p>

<p>Thanks to the support of the <a href="https://www.canarie.ca/" target="_blank">Canarie </a> program, this release introduces a <a href="https://github.com/obiba/opal/tree/master/opal-spi/src/main/java/org/obiba/opal/spi/datasource"target="_blank">datasource plugin service interface </a> that allows to import data:</p>

<ul>
    <li>from a file (for instance <a href="https://github.com/obiba/opal-datasource-spss" target="_blank">SPSS </a>),
    </li>
    <li>from a database (for instance <a href="https://github.com/obiba/opal-datasource-limesurvey" target="_blank">Limesurvey </a>),
    </li>
    <li>from an application web services (for instance <a href="https://github.com/obiba/opal-datasource-redcap" target="_blank">REDCap </a>).
    </li>
</ul>

<p>Plugins are available from our <a href="https://plugins.obiba.org/" target="_blank"> plugin repository </a>. Please contact us if you want to develop and refer a new plugin.</p>

<p>Other notable features are:</p>

<ul>
    <li>the identifier mapping (at import and export) applies to variable values declared as being entity identifiers (<code>referenced entity type</code> property),</li>
    <li>SPSS missing discrete values and ranges are now mapped to missing categories, both at import and export,</li>
    <li>system log files can be downloaded from the administration pages,</li>
    <li>users with "Add table" permission can import data,</li>
    <li>SSL connection with MongoDB is now supported,</li>
    <li>user ban policy has been added (temporary ban after several login failures).</li>
</ul>

<p>See <a href="http://opaldoc.obiba.org" target="_blank">Opal documentation </a> for installation and operation instructions.</p>
