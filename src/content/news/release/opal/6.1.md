<p>We are pleased to announce that Opal 6.1 is now available. <a
    href="https://www.obiba.org/pages/products/opal/">Opal</a> is OBiBa’s core data management application
  for biobanks.</p>

<p>
  This Opal release includes:
</p>

<ul>
    <li><strong>Import from Amber</strong>: case reports and interviews can be imported directly from an <a href="/pages/products/amber/">Amber</a> server, using an Amber API key, including the collected files. Interviews can be filtered by campaign.
    </li>
    <li><strong>Geo variable summary</strong>: geographic variables have a summary page showing the points counted by H3 cell, the bounding box, the centroid and the missings. Raw coordinates are no longer returned.
    </li>
    <li><strong>Persistent tasks</strong>: tasks are stored in the configuration database, so that their history survives a restart. Expired tasks are deleted daily.
    </li>
    <li><strong>Entity lookup</strong>: entity identifiers are indexed, to find the tables of an entity without scanning them all.
    </li>
    <li><strong>File content viewer</strong>: the file view previews markdown, CSV/TSV (as a table), PDF, images and text files.
    </li>
    <li><strong>Security improvements</strong>: metadata rendered as markdown is sanitized, and a variable summary privacy setting (<code>summary.minN</code>) limits what summaries disclose to users who cannot see the values.
    </li>
    <li><strong>New look</strong>: the user interface was rebranded with the OBiBa design system.
    </li>
  </ul>

<p>
  See the <a href="https://github.com/obiba/opal/releases/tag/6.1.0" target="_blank">full release notes </a> for the complete list of changes.
</p>

<p>See also <a href="https://opaldoc.obiba.org/" target="_blank">Opal documentation </a> for installation and operation instructions.</p>
