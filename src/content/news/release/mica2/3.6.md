<p xmlns="http://www.w3.org/1999/html">We are pleased to announce that Mica2 3.6 is now available. <a href="/pages/products/mica/">Mica</a> is OBiBa’s data web portal for epidemiological studies and networks.</p>

<p>This release introduces the following:</p>

<ul>
    <li><b>Individual Study Model</b>, the Access section has been extended to capture more details regarding data sharing and dissemination.
    </li>
    <li><b>Opal Views Download</b>, this feature permits Mica users to generated and archive importable Opal Views based on variable lists.
    </li>
</ul>

<div class="alert alert-warning obiba-top-margin" role="alert">

  <p>Only users wishing to update their <code>Individual Study</code> model to have the new <code>Access</code> section must follow the following data migration steps:</p>
  </br>

  <ul>
    <li>
      Stop Mica database.</li>
    <li>
    <li>
      <strong>Backup</strong> Mica database.</li>
    <li>
    Go to <code>Administration > Individual Study Configuration</code> and update your current <emphasis>schema</emphasis> and <emphasis>definition</emphasis> using this <a href="https://github.com/obiba/mica2/blob/master/mica-core/src/main/resources/config/study-form/collection-schema.json" target="_blank">schema</a> and <a href="https://github.com/obiba/mica2/blob/master/mica-core/src/main/resources/config/study-form/collection-definition.json" target="_blank">definition</a> and save the changes.
    </li>
    <li>
      Unzip <a href="https://github.com/obiba/mica2/releases/download/3.6.0/access-section-update-migration.zip">access-section-update-migration.zip</a> and run the migration script <code>./access_migration.sh</code>.
    </li>
    <li>Restart Mica server
    </li>
    <li>
      Go to <code>Administration > Individual Study Configuration > Search (TAB)</code> and save so the <code>Individual Study</code> taxonomies get re-indexed.
    </li>
    <li>Go to <code>Administration > Indexing</code> and index Studies.
    </li>
  </ul>
</div>

<p>See <a href="http://micadoc.obiba.org" target="_blank">Mica documentation </a> for installation and operation instructions.</p>
