<p xmlns="http://www.w3.org/1999/html">We are pleased to announce that Mica2 4.4 is now available. <a href="/pages/products/mica/">Mica</a> is OBiBa’s data web portal for epidemiological studies and networks.</p>

<p>This release introduces the following features in the public pages (pages of the published content):</p>

<ul>
  <li><b>Lists</b>, selected variables can be added in a cart or saved into a named list.
  </li>
  <li><b>Search</b>, many <a href="http://micadoc.obiba.org/en/latest/admin/pub-configuration.html#search-page-settings" target="_blank">new settings </a> for configuring the search request, results extraction, sorting and display.
    Coverage filters added (full coverage, subdomains with variables).
  </li>
  <li><b>Variable summary statistics</b> are improved (% per missing/non-missing values, per harmonized variables).
  </li>
  <li><b>Data Access Request archiving</b> is possible when the project is completed (project was approved and end date is expired).
  </li>
  <li><b>Data Access Request report notifications</b> are sent to the Data Access Officers as well (requires Agate 2.1.3).
  </li>
  <li><b>Templates</b> are more responsive, many robustness improvements.
  </li>
</ul>

<p>This release also introduces the following features in the administration pages:</p>

<ul>
  <li><b>Contact Us notifications</b>, feature and recipients are configurable.
  </li>
</ul>

<p>See <a href="http://micadoc.obiba.org/en/latest/admin/pub-configuration.html" target="_blank">Public pages configuration </a> in the Mica documentation for the details on how to configure and customize your data portal front-end.</p>
