<p xmlns="http://www.w3.org/1999/html">We are pleased to announce that Mica2 5.0 is now available. <a href="/pages/products/mica/">Mica</a> is OBiBa’s data web portal for epidemiological studies and harmonization initiatives.</p>

<p>To account for the new standards proposed by <a href="https://www.maelstrom-research.org" target="_blank">Maelstrom Research </a> to document harmonization initiatives and outputs, this release includes the following modifications:</p>

<ul>
  <li>The entity of Harmonization Initiative replaces Harmonization Study.
  </li>
  <li>The entity of Harmonization Protocol replaces Harmonized Dataset.
  </li>
  <li>New fields in both entities are added to better describe the harmonization process.
  </li>
  <li>The Population and Harmonization Design fields are removed from the Harmonization Study (now Harmonization Initiative).
  </li>
  <li>Two distinct search pages are created specifically for: Individual Studies and Harmonization Initiatives.
  </li>
</ul>

<div class="alert alert-warning obiba-top-margin" role="alert">
  <p>Please review <a href="https://github.com/obiba/mica2/wiki/Mica-5.0-Upgrade-Notes" target="_blank">Mica 5.0 Upgrade Notes </a> before upgrading your current installation of Mica.</p>
</div>

<p>This release also includes the following features:</p>

<ul>
  <li>Data Access Requests can be archived regardless of their status.
  </li>
  <li>Data Access Requests archive operations are logged as an action and therefore recorded in the history.
  </li>
  <li>Notifications are disabled when a Data Access Request is archived.
  </li>
  <li>Two-factor authentication can be enabled for enhanced security (also see <a href="/pages/news/release/agate/2.6/">Agate 2.6</a>).
  </li>
  <li>Login is not required to use the cart (configurable).
  </li>
</ul>
