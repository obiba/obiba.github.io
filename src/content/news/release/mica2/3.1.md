title: "Mica 3.1 Released"
date: "2017-11-21"
product: "mica"
summary: "Faceted search for document lists and search plugin"
---

<p>We are pleased to announce that Mica2 3.1 is now available. <a href="/pages/products/mica/">Mica</a> is OBiBa’s data web portal for epidemiological studies and networks.</p>

<p>This release offers the following elements to improve user experience when listing and searching for documents:</p>

<ul>
	<li>The provision of a suggestion-box to help users narrow down their search.</li>
	<li>The possibility to further refine study lists through a faceted search.</li>
    <li>The addition of "relevance" as a new sort criteria, making the keyword search more efficient.</li>
</ul>
</br>
<p>In addition, this release provides:</p>

<ul>
    <li>The introduction of Mica's search engine as a plugin, making upgrades to newer versions much simpler.</li>
    <li>The addition of a detailed report on studies, providing more information on study characteristics such as the number of participants, types of subpopulations, data collections events, and more.</li>
</ul>
</br>
<p>See also <a href="http://wiki.obiba.org/display/MICADOC" target="_blank">Mica documentation </a> for installation and operation instructions.</p>
