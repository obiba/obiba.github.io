<p xmlns="http://www.w3.org/1999/html">We are pleased to announce that Mica2 3.5 is now available. <a href="/pages/products/mica/">Mica</a> is OBiBa’s data web portal for epidemiological studies and networks.</p>

<p>This release introduces the following:</p>

<ul>
    <li><b>Variable Lists</b>, enable the researcher to name and save search results for data exploitation which include: exploring data dictionaries, obtaining taxonomy coverage statistics, searching entities and binding variables to a data access request.
    </li>
    <li><b>Variable Cart</b>, is an <em>unnamed</em> list that is bound to the current user and the browser. By default an anonymous Mica Portal user will have a variable cart.
    </li>
</ul>

<div class="alert alert-warning obiba-top-margin" role="alert">
	<p>Make sure to review and change the Lists and Cart configurations to adapt them to your needs.</p>
</div>

<p>See <a href="http://micadoc.obiba.org" target="_blank">Mica documentation </a> for installation and operation instructions.</p>
