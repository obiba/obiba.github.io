---
title: "Mica 4.3 Released"
date: "2020-10-01"
product: "mica"
summary: "Crosstab, Cart, Contact Us pages, Search graphics, Files browser, Variables classifications, context path"
---

<p xmlns="http://www.w3.org/1999/html">We are pleased to announce that Mica2 4.3 is now available. <a href="/pages/products/mica/">Mica</a> is OBiBa’s data web portal for epidemiological studies and networks.</p>

<p>This release introduces the following features in the public pages (pages of the published content):</p>

<ul>
  <li><b>Crosstab</b>, the page for performing contingency table analysis within a dataset.
  </li>
  <li><b>Cart</b>, a cart to store selected variables when browsing the portal (from variable, dataset or search pages).
  </li>
  <li><b>Contact Us</b>, the page to send a contact request to the administrators and data access officers.
  </li>
  <li><b>Project</b>, the page to display the details of an approved project.
  </li>
  <li><b>Variables classifications</b>, a chart to display the coverage of a taxonomy by the variables annotations. Available at the network, study or dataset level.
  </li>
  <li><b>File browser</b>, to navigate and download the files associated to a network, study, population, data collection event or dataset.
  </li>
  <li><b>Search graphics</b>, to visualize the results of a query as geo, pie or bar charts.
  </li>
  <li><b>Search download</b>, to download the results of a query.
  </li>
  <li><b>Search query copy</b>, to copy the query string, for the R or Python API.
  </li>
</ul>

<p>This release also introduces the following features in the administration pages:</p>

<ul>
  <li><b>Revision Comparisons</b>, now provide difference highlighting and selective restoring.
  </li>
  <li><b>Document Listings</b>, introduce an improved search and sorting.
  </li>
</ul>

<p>See <a href="http://micadoc.obiba.org/en/latest/admin/pub-configuration.html" target="_blank">Public pages configuration </a> in the Mica documentation for the details on how to configure and customize your data portal front-end.</p>

<p>
  Mica server can be run in a context path: the server URL can now be <code>https://example.org/mica</code> and not just in a subdomain such as <code>https://mica.example.org</code>.
</p>
