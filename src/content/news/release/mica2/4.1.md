<p xmlns="http://www.w3.org/1999/html">We are pleased to announce that Mica2 4.1 is now available. <a href="/pages/products/mica/">Mica</a> is OBiBa’s data web portal for epidemiological studies and networks.</p>

<p>This release introduces the following new features:</p>

<ul>
  <li><b>Study Import</b>, enables researchers to share study descriptions from remote Mica servers having identical data model - courtesy of <a href="https://recap-preterm.eu/" target="_blank">RECAP Preterm </a> and <a href="https://www.eucanconnect.eu/" target="_blank">EUCAN-Connect </a>.
  </li>
  <li><b>Persons Management</b>, administrators can now search, delete and update persons (contacts, investigators) associated with different studies and networks.
  </li>
</ul>

<p>See <a href="http://micadoc.obiba.org" target="_blank">Mica documentation </a> for installation and operation instructions. Note that a <a href="http://micadoc.obiba.org/en/latest/admin/installation.html#docker-image-installation" target="_blank">Docker Image Installation </a> section has been added.</p>
