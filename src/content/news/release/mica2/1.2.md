<p>We are pleased to announce that Mica2 1.2 is now available. <a href="/pages/products/mica/">Mica</a> is OBiBa’s data web portal for biobanks.</p>

<p>The main new features are:</p>
<ul>
    <li>New search interface and API, very flexible and performant,
    </li>
    <li>Addition of graphics on Mica content: geographical distribution, study design distribution etc.,
    </li>
    <li>Improved attached files navigation and access controls.
    </li>
</ul>

<p>
  Mica2 server upgrade from 1.1 will not affect the data. For the Mica Drupal modules and theme, see <a href="http://wiki.obiba.org/display/MICADOC/Mica+Drupal+Client+Installation+Guide#MicaDrupalClientInstallationGuide-DrupalModulesandThemeUpgrade" target="_blank">upgrade instructions </a>.
</p>

<p>See also <a href="http://wiki.obiba.org/display/MICADOC" target="_blank">Mica documentation </a> for installation and operation instructions.</p>
