<p xmlns="http://www.w3.org/1999/html">
  We are pleased to announce that Mica2 6.0 is now available.
  <a href="/pages/products/mica/">Mica</a> is OBiBa's data web portal for epidemiological studies and harmonization initiatives.
</p>

<p>This Mica 6.0 release requires Java 21.</p>

<p><b>Upgrade actions</b>:</p>

<ul>
  <li>
    <b>Java runtime</b>: If the default Java installed in your system is not Java 21, you must install Java 21 (any vendor), update the path to the <em>java</em> executable in the file
    <code>/etc/default/mica2</code>, and restart the <code>mica2</code> service.
  </li>
  <li>
    <b>Plugins</b>:
    <ul>
      <li>
        <b>Mica Search Plugin</b>: The latest Mica search plugin is downloaded on the first run of Mica 6.0. Update settings like <code>clusterName</code> and <code>transportAddresses</code> in
        <code>site.properties</code> file.
      </li>
      <li>
        <b>Mica Tables SPSS</b> and <b>Mica Taxonomies Files</b>: Unzip the latest versions as directories under <code>MICA_HOME/plugins</code> and update their <code>site.properties</code> settings
        accordingly.
      </li>
    </ul>
  </li>
</ul>

<p><b>Other new features</b>:</p>

<ul>
  <li>Added configurable roles mapping from groups.</li>
  <li>Support for no search engine when using Mica solely for data access workflows.</li>
  <li>Addition of new permissions for different levels of variable summary visibility.</li>
</ul>

<p><b>Additional notes</b>:</p>

<ul>
  <li><b>Important</b>: Mica 6.0 no longer has an embedded Elasticsearch. An external Elasticsearch 8.16.1 instance is now required.</li>
  <li>Mica 6.0 requires Elasticsearch 8.16.1, older versions are no longer supported.</li>
  <li>
    When deploying Mica with Docker, use Elasticsearch 8.16.1 as a Docker container for easy setup. See
    <a
      href="https://micadoc.obiba.org/en/latest/admin/installation.html#docker-image-installation"
      target="b_blanck"
      >Docker Image Installation <i class="fa fa-external-link-square"></i
    ></a>
    for details.
  </li>
  <li>The Mica API has NOT been modified: it will seamlessly integrate with <b>MicaR</b> and <b>Mica Python Client</b>.</li>
  <li>Mica 6.0 is compatible with older versions of <b>Opal</b> and <b>Agate</b>.</li>
</ul>
