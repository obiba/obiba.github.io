---
title: "Mica 4.5 Released"
date: "2021-06-01"
product: "mica"
summary: "Improved document listing public pages, Opal Personal Access Token"
---

<p xmlns="http://www.w3.org/1999/html">We are pleased to announce that Mica2 4.5 is now available. <a href="/pages/products/mica/">Mica</a> is OBiBa’s data web portal for epidemiological studies and networks.</p>

<p>This release introduces the following features:</p>

<ul>
  <li>Option to use an <a href="https://opaldoc.obiba.org/en/latest/web-user-guide/my-profile.html#personal-access-tokens" target="_blank">Opal Personal Access Token </a> for Opal authentication in place of a username and password.
  </li>
  <li>New annotation column in downloaded list of variables.
  </li>
  <li>New <b>Card</b> display with statistics, search and sort fields in Network, Study and Dataset listing pages.
  </li>
  <li>New harmonization status <b>Partial</b> to describe variables that could generate DataSchema with possible loss of information. The harmonization status legend has its own separate template: <code>models/harmonization.ftl</code>.
  </li>
  <li>New graphical summary statistics section in Network public detail page.
  </li>
  <li>Best efforts are done to get clients' IP, despite the reverse proxies, so that it appears in the web services resquests log (rest.log),
  </li>
  <li>Dependency on Google fonts service removed, so that pages work in restricted environments.
  </li>
</ul>

<p>The following main templates have been modified:</p>

<ul>
  <li><b>dataset.ftl</b>: addition of the <code>harmonizationLegend</code> macro section.
  </li>
  <li><b>datasets.ftl</b>: modification of the <code>datasetCardModel</code> macro section.
  </li>
  <li><b>network.ftl</b>: addition of the graphical summaries section.
  </li>
  <li><b>networks.ftl</b>: modification of the <code>networkCardModel</code> macro section.
  </li>
  <li><b>search.ftl</b>: data collection event checkbox changed for a switch widget in the coverage display.
  </li>
  <li><b>studies.ftl</b>: modification of the <code>studyCardModel</code> macro section.
  </li>
  <li><b>variable.ftl</b>: addition of the <code>harmonizationLegend</code> macro section.
  </li>
</ul>
