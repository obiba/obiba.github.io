<p xmlns="http://www.w3.org/1999/html">We are pleased to announce that Mica2 4.2 is now available. <a href="/pages/products/mica/">Mica</a> is OBiBa’s data web portal for epidemiological studies and networks.</p>

<p>This release introduces the following new administration features:</p>

<ul>
  <li><b>Revision Comparison</b>, permits the comparison of two revisions of a Mica content document (Network, Study, etc).
  </li>
  <li><b>Content Statistics Summary</b>, provides the count of all Mica content documents by revision status (Published, Under Review, In Edition, etc) as well as the count of all their associated files and variables</a>.
  </li>
  <li><b>Filtering by Revision Status</b>, Mica content document listing can be filtered by revision status.</a>.
  </li>
</ul>

<p>See <a href="http://micadoc.obiba.org" target="_blank">Mica documentation </a> for installation and operation instructions. Note that a <a href="http://micadoc.obiba.org/en/latest/admin/installation.html#docker-image-installation" target="_blank">Docker Image Installation </a> section has been added.</p>
