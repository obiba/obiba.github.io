<p xmlns="http://www.w3.org/1999/html">We are pleased to announce that Mica2 3.8 is now available. <a href="/pages/products/mica/">Mica</a> is OBiBa’s data web portal for epidemiological studies and networks.</p>

<p>This release introduces several changes to Data Access Request:</p>

<ul>
    <li><b>New notification when a request is created.
    </li>
    <li><b>Project timeline within a request.
    </li>
    <li><b>Ability to change a project start date.
    </li>
    <li><b>Being informed about annual and final report dates.
    </li>
</ul>

<p>See <a href="http://micadoc.obiba.org" target="_blank">Mica documentation </a> for installation and operation instructions.</p>
