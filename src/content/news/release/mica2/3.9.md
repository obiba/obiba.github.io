<p xmlns="http://www.w3.org/1999/html">We are pleased to announce that Mica2 3.9 is now available. <a href="/pages/products/mica/">Mica</a> is OBiBa’s data web portal for epidemiological studies and networks.</p>

<p>This release enables the search engine to use the upcoming search plugin compatible with Elasticsearch 7.</p>

<p>See <a href="http://micadoc.obiba.org" target="_blank">Mica documentation </a> for installation and operation instructions.</p>
