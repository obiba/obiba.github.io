<p>We are pleased to announce that Mica 9.2 is now available.</p>

<p>This release contains the following features and improvements:</p>

<ul>
  <li>Ajax statistics tables in detail page variables</li>
  <li>SSL version option removed</li>
  <li>Capability of personalizing Opal connection error messages</li>
  <li>Permission config made possible to view stats in variable page</li>
  <li>Deal with studies title if no acronym was not defined</li>
  <li>Performance enhancement in domain coverage module</li>
  <li>Added configuration menu to display/hide buttons Study/Datashema coverage</li>
  <li>Upgraded jQuery DataTable library</li>
  <li>Added more information in Network search page</li>
  <li>Added attached studies field in variable page</li>
  <li>Added capability of searching variables of a study</li>
  <li>Added capability of searching studies of a network</li>
  <li>Changed timeline scale for studies with duration greater than 50 years</li>
</ul>
