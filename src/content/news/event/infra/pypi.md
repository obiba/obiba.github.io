title: "OBiBa in the PyPi"
date: "2023-02-14"
summary: "Opal, Mica and Agate Python packages in the PyPi"
---

<p>OBiBa Python packages are now published in the official Python Package Index (PyPi):</p>

<p>These packages are meant to make administrative operations on their respective OBiBa application. See the <a href="https://pypi.org/search/?q=obiba" target="_blank">OBiBa Python packages on PyPi </a>.</p>

<ul>
		<li><b>obiba-opal</b> is the Opal Python client (see <a href="https://opaldoc.obiba.org/en/latest/python-user-guide/" target="_blank">Opal Python documentation </a>),
		</li>
		<li><b>obiba-mica</b> is the Mica Python client (see <a href="https://micadoc.obiba.org/en/latest/python-user-guide/" target="_blank">Mica Python documentation </a>),
		</li>
		<li><b>obiba-agate</b> is the Agate Python client (see <a href="https://agatedoc.obiba.org/en/latest/python-user-guide/" target="_blank">Agate Python documentation </a>).
		</li>
	</ul>
